# 安装与定制

## 安装

把 `snippets/obsidian-cinematic-ui.css` 复制到知识库的 `.obsidian/snippets/`，然后在 Obsidian 的「设置 → 外观 → CSS 代码片段」中刷新并启用。

## 快速定制

文件开头的 `:root` 提供常用参数：

- `--xwc-glow-rgb`：通用冷蓝辉光颜色，格式必须是 `R, G, B`。
- `--xwc-image-reveal-duration`：图片淡入时长。
- `--xwc-callout-breathe-duration`：警告类 Callout 的呼吸周期。

收件箱提醒默认匹配根目录 `📥收件箱`。如果你的目录名不同，请在 CSS 中修改 `[data-path="📥收件箱"]`。纯 CSS 无法可靠读取折叠目录是否为空，因此公开片段在该目录存在时显示提醒；本地生成器版本可以在生成时检查磁盘并仅对非空目录输出规则。

## 为什么没有附带壁纸

壁纸涉及版权、个人偏好和文件体积。这个项目只负责动效与语义样式，不请求外部图床，也不把任何私人素材编码进 CSS。你可以继续使用自己的主题壁纸或背景片段。

## 排查

- 样式没变化：先在 CSS 代码片段面板刷新，再关闭并重新开启片段。
- Callout 只有文字：确认 Markdown 使用 `> [!note]` 这样的标准语法。
- 主题覆盖颜色：本项目已使用独立 token；若第三方主题仍以更高优先级覆盖，请提交 issue，并附主题名称与 Obsidian 版本。
- 动画太强：调大呼吸周期，或在文件末尾取消警告族的 `animation`。
