# 安装与定制

## 选哪份

- 只想美化提示框：`cinematic-callouts.css`。
- 想要写作反馈：`cinematic-writing.css`。
- 想让目录滚动时保留上级路径：`cinematic-folders.css`，桌面可选模块。
- 想一次装好提示框和写作反馈：`obsidian-cinematic-ui.css`。

合集与两个单独模块二选一，避免重复启用。目录模块可另外开启。

## 安装

从 GitHub Release 下载分享包并解压。把选中的 CSS 复制到知识库的 `.obsidian/snippets/`，然后在「设置 → 外观 → CSS 代码片段」中刷新并启用。直接下载单个文件时，保存 GitHub 的 Raw 原文，避免把网页 HTML 保存成 CSS。

把 `examples/callouts.md` 或 `examples/writing.md` 复制进一个演示笔记，即可尝试效果。关闭片段开关就能恢复原有外观。

## 快速定制

文件开头的 `:root` 提供常用参数：

- `--xwc-glow-rgb`：冷蓝辉光颜色，格式为 `R, G, B`。浅色主题有单独的颜色覆盖。
- `--xwc-image-reveal-duration`：图片渲染时的淡入时长。
- `--xwc-callout-breathe-duration`：警告类 Callout 的呼吸周期。

目录模块的 `--xwc-folder-height` 控制行高与逐级停靠位置。六层使用不同色相，无需填写私人目录名。更深层级正常滚动。

系统启用「减弱动态效果」后，呼吸、入场和勾选动画停止；静态语义颜色仍保留。

## 验证范围

原始动效曾在 Blue Topaz 下验证；本次模块版用 Chromium 和模拟 Obsidian DOM 检查了目录停靠、减弱动态效果及深浅配色。完整原生 Obsidian 兼容性仍待验证，不承诺覆盖所有主题、移动端或目录插件。

图片动画响应渲染，不检测下载完成；复选框在重建视图时可能重播。当前公开包去掉了旧收件箱脉冲，因为纯 CSS 无法判断折叠目录是否有待整理文件。

## 展示素材

效果图与 GIF 使用虚构内容和实际发布 CSS 渲染，明确标记为预览；不包含私人笔记。没有附带壁纸或字体，可继续使用自己的主题配置。

## 排查

- 样式没变化：刷新片段，再关闭并重新开启。确认文件后缀为 `.css`。
- Callout 没有效果：确认使用 `> [!note]` 等标准 Markdown 语法。
- 目录停靠异常：先关闭目录模块；在默认主题或独立演示库复核，再反馈主题名与 Obsidian 版本。
- 动画太强：启用系统「减弱动态效果」，或关闭写作/提示框模块。
