# Folder demo

Create this fictional folder tree in a disposable vault. Add enough notes under
Release to make the file explorer scroll, then watch the ancestor titles stay visible.

```text
Studio/
  Projects/
    Field Notes/
      Release/
        Note 01.md
        Note 02.md
        ...
```

Enable cinematic-folders only. This optional desktop module supports six levels.
The rendered preview uses Obsidian-shaped HTML; verify behavior with your own
Obsidian version and theme. Dragging, folder collapse and mobile are not certified.
