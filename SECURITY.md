# Security reports

Please send suspected vulnerabilities in **obsidian-cinematic-ui** privately to [ai@widechaos.cn](mailto:ai@widechaos.cn). Include the affected commit or version, a short impact description and a minimal reproduction using synthetic data.

Do not put credentials, private documents, chat contents, real recordings or account information in public issues. An ordinary bug with a safe reproduction can use the [bug report form](https://github.com/widechaos/obsidian-cinematic-ui/issues/new/choose).

Test only systems and data you control. Keep local development servers on their documented loopback addresses. Optional third-party services and dependencies retain their own security/reporting channels.
